# Roadmap

## Completed foundation

- Modular puzzle source abstraction with chunked sync and incremental metadata
- Training mode framework (classic, timed, streak, theme, review)
- Localized UI scaffolding with English and Spanish baselines
- Board theme, piece style, coordinate style, and accessibility/voice settings
- Privacy documentation and release workflow scaffolding

## Next milestones

1. Add file-based import for decompressed Lichess archives on desktop.
2. Generate native desktop platform folders and enable signed artifact publishing.
3. Expand review mode with spaced-repetition scheduling weights.
4. Add more locales and translated accessibility guidance.
5. Introduce richer board assets/piece packs using openly licensed art.
